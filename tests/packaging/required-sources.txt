# Install sources this repository must ship.
#
# Every path here is named by the documentation as something a user installs from, or as
# something the installer skill reads. If one is missing from a FRESH CLONE, the documented
# install route is broken even though it works on the machine that wrote the docs — which is
# exactly the defect this file exists to prevent recurring. That defect was real: on 2026-08-26
# the repository documented .claude/skills/gstack-to-plans/SKILL.md while .gitignore kept it
# untracked, and nothing caught it.
#
# Format: one repo-relative path per line. Blank lines and # comments are ignored.
# Each entry must exist in the clone, be non-empty, and be TRACKED by Git.
#
# Do NOT list paths that belong to a user's project after installing a third-party tool
# (.claude/skills/gstack/, .claude/skills/brainstorming/, .claude/skills/phase-plan-creator/).
# Those are installed by gstack, superpowers and advanced-planning. They are not ours to ship.
